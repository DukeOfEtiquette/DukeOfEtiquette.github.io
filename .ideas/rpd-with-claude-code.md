- Provides an assistant that has expert knowledge (well, certainly expert relative to me...) on many more topics than just coding
- Allows me to quickly and easily save information for future reference
- Provides a simple "Research, Plan, Do" loop (a.k.a. the RPD loop)

## Research

- This is the default, typical experience most folks have had with these models
- If given instructions it will try to "do" them, but default to asking for permission for each change
- Most effective when you ask questions and explore together
- "get on the same page" phase of a workflow

## Plan

- Start when you have a solid idea of what you want to do
- This phase is often iterative
- Initial plan might need small adjustments
- Sometimes good to drop back into Research and ask clarifying questions about the plan or clear up steps that are still ambiguous

## Do

- This is when I start editing
- Depending on my confidence in the plan, I can have it edit without asking permission or still have it ask yes/no for each edit
